# Kitbash Overzicht

Overzicht van de kitbash-cursisten per fase: bedenken, samenstellen en afwerken.

- `index.html` is de hele site. Het Hanze-logo zit in het bestand zelf.
- Foto's van cursisten horen in de map `afbeeldingen/fotos/` naast `index.html`.
- De gegevens worden online opgeslagen in Supabase.
- De site staat live op Netlify: https://kitbash-bord.netlify.app/
